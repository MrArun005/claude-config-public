**8 weeks at 3h/day** (starting 2026-08-12 → ~2026-10-07):

| Weeks | Focus |
|---|---|
| 1-2 | JavaScript: closures, event loop, promises/async-await, `this`, prototypes, debounce/throttle, memory leaks |
| 3-4 | React + TypeScript: hooks, rendering, reconciliation, Context, Redux Toolkit, Suspense, lazy loading, generics, utility types |
| 5 | Browser internals + performance: rendering pipeline, reflow/repaint, Core Web Vitals, bundle optimisation, caching |
| 6 | Frontend system design + testing: dashboards, infinite scroll, component libraries, Jest, RTL, Cypress |
| 7 | DSA for frontend: arrays, strings, hash maps, sliding window, two pointers, stacks, queues, trees |
| 8 | Mock interviews + behavioural |

**Daily split:** 45min theory / 60min coding / 30min explaining aloud / 30min debugging or system design / 15min revision.

**Answer framework** (the distinctive bit — what makes a 4+ year engineer sound experienced):
`Definition → How it works → Code example → Real project example → Trade-offs`

**Frontend system design framework:** requirements → architecture → state management → data fetching → performance → error handling → accessibility → testing.

**Behavioural (STAR) stories to prepare:** difficult bug, performance improvement, production incident, leading a feature, mentoring, conflict resolution, tight deadline.
